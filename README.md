# UART SMS Forwarder - Multi Device

多设备短信转发系统，支持同时管理多个 USB SIM 卡设备。
Air780 短信UART转发器

## 功能特性

- 🔄 多设备支持：一个容器管理多个 USB SIM 卡
- 📱 统一 Web UI：短信发送、设备状态监控
- 📨 通知增强：短信/来电通知显示接收设备信息
- 🔌 设备热插拔：配置文件管理，无需修改代码
